# 眠宝患者服务交互原型

主界面采用手机宽度，支持电脑与手机浏览器。电脑端左侧为可编辑的页面模块需求，中间为页面，右侧为修改意见；二级页隐藏首页底部导航。

## 启动与保存

在本目录运行 `python3 server.py`，访问 http://127.0.0.1:8765/ 。本地服务保存左侧说明与右侧意见时写回本目录 index.html；编辑说明不改变中间页面。患者记录保存在当前浏览器。

## 当前功能

- 立即登录：微信样式手机号授权，授权后进入首页；协议可主动查看。
- 首页：轮播、晨起状态、眠宝用药引导弹窗、小憩设置与倒计时、药房地图、患者福利、病程记录等入口。
- 专病管理：猝倒记录、自然月日历、周趋势、量表与睡眠辅助工具。
- 病程记录：合并原语音病历与图片病程功能。相册或拍照上传后显示整理等待弹窗，支持查看原图；底部长按语音显示微信风格弹窗，上滑取消，松开进入转文字与整理流程。展示原话和优化内容，时间、症状、次数标红，原始描述与提取值可修改；就诊与用药补充信息可展开核对。同一条记录可补充图片和语音，人工修改优先保留。支持草稿恢复、重试、手动填写、保存和历史筛选；兼容旧图片与语音记录。记录不会自动写入用药任务或猝倒统计。
- 眠宝帮您：既有主题问答、创新支付申请、病历夹与用药等流程。
- 知识中心：六篇患教文章，支持分类筛选和文章详情，返回保留分类与滚动位置。
- 我的：记录汇总、个人档案与设置等入口。

## 接入范围

病程记录当前为 Demo 转写与提取效果，不采集真实音频、不调用真实 OCR 或大模型。图片可上传、查看和保存，字段由示例结果填写后供用户核对。眠宝问答未接真实模型，支付、购药、预约与服务履约尚无真实业务接口。文章和量表相关内容需正式医学审核，不用于医疗判断。

药房地图需要网络与定位授权。页面语音输入若调用浏览器识别，受浏览器支持与权限影响；病程记录长按语音采用固定示例体验。小憩计时依赖页面运行，未接系统通知。

后续调整默认仅在本地进行；明确要求发布时再更新 GitHub。

## 在线版保存方式

根目录为 GitHub Pages 静态网站。患者记录、左侧说明与右侧修改意见保存在当前设备浏览器，不跨设备同步，不写回 GitHub。local-preview/ 保留完整本地项目及写回 HTML 的服务。
