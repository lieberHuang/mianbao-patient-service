# 发作性睡病之家 · 交互原型

主界面采用手机宽度，支持电脑与手机浏览器。电脑端左侧为可编辑的页面模块需求，中间为页面，右侧为修改意见；二级页隐藏首页底部导航。

## 启动与保存

在本目录运行 `python3 server.py`，访问 http://127.0.0.1:8765/ 。本地服务保存左侧说明与右侧意见时写回本目录 index.html；编辑说明不改变中间页面。患者记录保存在当前浏览器。

## 当前功能

- 立即登录：微信样式手机号授权，授权后进入首页；协议可主动查看。
- 首页：发作性睡病之家标题、眠宝问候、轮播、晨起状态、药房地图、患者福利、病程记录等入口；状态卡片仅展示静态反馈。
- 健康档案：月度猝倒记录、底部快速记录、周趋势、ESS/SRSS最近七次测评分数。
- 病程记录：新建时先由底部弹窗选择语音或图片方式，进入对应录入页；可切换补充并保留资料。合并原语音病历与图片病程功能。相册或拍照上传后显示整理等待弹窗，支持查看原图；底部长按语音显示微信风格弹窗，上滑取消，松开进入转文字与整理流程。保留原始图片和语音原文，关键信息仅显示可编辑的时间与描述；描述包含提取到的症状、次数等信息，不显示提取示例标签。旧结构化结果在内部保留。同一条记录可补充图片和语音，人工修改优先保留。支持草稿恢复、重试、手动填写、保存和统一历史列表；兼容旧图片与语音记录。记录不会自动写入用药任务或猝倒统计。
- 眠宝帮您：既有主题问答、创新支付申请、病历夹与用药等流程。
- 知识中心：六篇患教文章，支持分类筛选和文章详情，返回保留分类与滚动位置。
- 我的：固定用户ID、个人档案与设置入口。

## 接入范围

病程记录当前为 Demo 转写与提取效果，不采集真实音频、不调用真实 OCR 或大模型。图片可上传、查看和保存，字段由示例结果填写后供用户核对。眠宝问答未接真实模型，支付、购药、预约与服务履约尚无真实业务接口。文章和量表相关内容需正式医学审核，不用于医疗判断。

药房地图需要网络与定位授权。页面语音输入若调用浏览器识别，受浏览器支持与权限影响；病程记录长按语音采用固定示例体验。小憩计时依赖页面运行，未接系统通知。

后续调整默认仅在本地进行；明确要求发布时再更新 GitHub。

## 品牌与引导

小程序统一名称为“发作性睡病之家”。眠宝保留为陪伴角色，“眠宝帮您”仍为助手功能名。登录、首页、授权与协议使用统一品牌；建档、病程录入/整理/核对、知识阅读及助手欢迎区使用眠宝口吻引导。改名不修改本地数据键或患者记录。

## 清空助手会话

左侧页面说明下方提供“清空聊天记录”按钮，查看和编辑说明时均可使用。点击后清空眠宝帮您的当前及历史会话；未打开助手时也可操作。保留已保存的病程、用药、附件、资料与申请，不清除左侧说明或右侧意见。

## 眠宝帮您：语音、图片与病程弹窗

输入框新增微信形式的语音与图片按钮，点击直接发送示例内容。图片发送后显示三个操作：记录病程并且发起新的患者福利申请、仅记录病程、仅申请理赔。前两项保存同一图片病程，组合项再进入福利申请；仅理赔不新建病程，进入后报销申请并携带示例图片；语音发送后确认是否记录到病程，确认才保存，重复操作使用同一消息ID去重。记录病程按钮从底部打开首页同一病程模块，支持原图片/语音录入、核对、草稿和保存。主病程记录与助手列表通过稳定ID关联，助手内查看修改打开同一记录。其他页面界面不变。
