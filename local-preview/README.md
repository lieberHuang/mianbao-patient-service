# 眠宝患者服务交互原型

基于两张概念图与《发作性睡病单药品小程序功能分析》制作的**本地 HTML 原型**。主界面采用手机宽度，电脑与手机浏览器均可使用。底部导航仅在五个一级页面展示；所有二级页面隐藏底部导航，并通过顶部返回按钮返回来源页。

电脑端左侧为**当前页面需求描述**，中间为交互原型，右侧为**当前页面修改意见**。三处会随一级页和二级页切换。保存右侧意见后，内容会写进项目的 `index.html`，并立即显示在左侧的“本页修改意见”区。窄屏下可点击“修改意见”按钮打开右侧意见窗口。

左侧说明面向开发，**39 个页面都按实际区域拆分为独立模块**。每块分别填写“展示与操作、字段与数据、状态与逻辑”；点击模块上的“编辑”可直接定位编辑，编辑页可添加或删除模块。原有页面级“事件与流转、字段与数据、状态与逻辑、接口与待接入”保留在可展开的“页面通用规则”中。点击“保存说明”后，该页说明写入 `index.html`，刷新、换浏览器或复制项目后仍可看到。可点击“恢复默认”移除该页自定义说明。旧版保存在浏览器内的说明会在打开本地服务时迁入文件。编辑左侧说明仅改变说明面板，不改变中间页面的功能、交互与样式。

## 启动

在项目目录运行：

```bash
python3 server.py
```

随后访问 `http://127.0.0.1:8765/`。**保存左侧说明或右侧修改意见必须通过此服务打开**，因为静态 HTML 页面本身无法写回文件。仅浏览时，也可以双击 `index.html`。

项目无需安装依赖，使用系统字体。`server.py` 只监听本机 `127.0.0.1`。药房地图在用户授权定位后需要联网加载 OpenStreetMap 地图及附近药店数据。

## 可体验的流程

- 首页：每日一次晨起状态选择、与商保领取状态联动的眠宝文案、服药底部弹窗、小憩计时、药房地图、“我的专员”及“用药提醒”入口。用药提醒可保存每日时间和通知偏好。
- 专病管理：本月与今日猝倒次数合并展示在一张卡片中；可快速记录猝倒、查看周趋势、切换 ESS／SRSS 记录，以及使用睡眠工具。
- 眠宝帮你：医生形象眠宝欢迎页、主题问答、复诊意向、随访与紧急咨询说明。
- 权益中心：商保直付演示流转、商保计算器、特定药品福利申请。
- 我的：记录汇总、计划设置、通知偏好、用户协议接入说明、退出演示及注销演示账户。

打卡、量表照片和其他业务记录保存在当前浏览器的 `localStorage`，清除浏览器数据后会消失。药房定位坐标仅保存在页面会话中；授权后会发给 OpenStreetMap 地图和 Overpass 查询服务。**左侧页面说明和右侧修改意见均写入 `index.html`**，可随项目文件一起复制。两类内容各按页面单独保存，互不覆盖。

## 原型边界

- ESS 页面使用占位题干，**不是正式量表**；演示分数不能用于医学判断。
- AI 仅按关键词返回固定演示文案，未连接 KnowDrug.ai 或医学知识库。
- 不良反应记录只保存在本地，未连接药物警戒系统。
- 药房地图与药店名称来自开放地图；营业状态、药品库存和合作资格未接入，购药、医院预约、随访、保险及福利也没有真实交易或履约接口。
- 量表照片仅保存在当前浏览器，原型不做图片识别或得分医学解释。
- 小憩计时仅在网页打开期间运行，不发送系统级提醒。
- 商保状态只在本地切换，不能证明真实领取资格；“我的专员”二维码目前不可扫描。通知开关仅保存偏好，尚未接入系统通知。

正式开发前，需确认药品与病种名称、量表授权、医学内容审核、服务履约方、个人信息处理及相关权益规则。

## 眠宝帮你输入

“眠宝帮你”首页和四类主题聊天页均提供底部固定输入栏。文字输入后点击发送；点击麦克风请求浏览器语音识别，识别结果可编辑且不会自动发送。实际识别取决于浏览器支持和麦克风权限，平台可能使用其语音服务；不支持时仍可使用文字或系统键盘听写。当前问答回复仍为已有本地文案。
